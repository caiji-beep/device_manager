# 开发记录与建议

这份文档不是代码说明，而是给项目后续迭代时使用的开发提示。

## 1. 模块推进建议

每新增一个模块，建议固定走下面的流程：

1. 明确硬件接口
2. 修改 DTS
3. 验证驱动匹配与 `/dev/...`
4. 编写最小 CLI
5. 再集成进 Qt
6. 最后补模块文档

## 2. 文档维护建议

根 `README.md` 只保留：
- 项目定位
- 结构概览
- 阅读入口
- 当前状态

不要把每个模块的细节都塞进首页。  
详细内容放进：

- `docs/DRIVER_DTS_SUMMARY.md`
- `docs/QT_APP_LSZ_TERMINAL.md`
- `docs/modules/*.md`

## 3. Qt 应用扩展建议

后续新增模块时，建议继续保持：

- 主窗口只负责导航与状态栏
- 每个功能单独成页
- 周期采集逻辑放进 Worker
- 设备访问逻辑放进 `device/*`

## 4. 目前最自然的后续方向

- 完善传感器线程停止与错误处理
- 给串口页增加更多命令辅助
- 给传感器页增加历史数据或状态记录
- 新增其它外设模块并继续按现有模式整理
