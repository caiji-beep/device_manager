# ICM20608 模块说明

## 1. 模块定位

ICM20608 是当前项目中的 SPI 惯性传感器模块，用来读取：

- Gyroscope（角速度）
- Accelerometer（加速度）
- Temperature（温度）

相比 AP3216C，ICM20608 更适合用作“周期采集 + 后续扩展”的练习对象。

---

## 2. 硬件与设备树

### 总线
- SPI：`ecspi3`

### 设备树节点
位于 `dts/imx-emmc.dts` 的 `&ecspi3` 下，核心信息为：

- `fsl,spi-num-chipselects = <1>`
- `cs-gpios = <&gpio1 20 GPIO_ACTIVE_LOW>`
- `compatible = "lsz,icm20608"`
- `spi-max-frequency = <8000000>`
- `reg = <0>`

这说明：
- ICM20608 挂接在 `ecspi3`
- 使用 0 号片选
- 最大 SPI 时钟设置为 8 MHz

---

## 3. 驱动层

### 路径
- `drivers/icm20608/`

### 用户态接口
驱动导出：
- `/dev/icm20608`

ICM20608 与 AP3216C 的共同点是都走字符设备接口；不同点是它底层基于 SPI 而不是 I2C。

---

## 4. Qt 设备封装层

### 路径
- `apps/qt_app/LSZ_Terminal/device/icm20608device.*`

### 当前做法
`Icm20608Device::readData(...)` 读取一组原始 short 数据后，已经进一步做了工程单位换算：

- Gyro：`/16.4f`
- Accel：`/2048.0f`
- Temp：按公式换算为摄氏度

因此，Qt UI 最终拿到的不是寄存器原始值，而是：

- `gyroX / gyroY / gyroZ`：`°/s`
- `accelX / accelY / accelZ`：`g`
- `temp`：`°C`

这使得页面层只负责显示，不必再关心单位换算。

---

## 5. Qt 采集线程层

### 路径
- `apps/qt_app/LSZ_Terminal/workers/icm20608worker.*`

### 结构
- `Icm20608Worker` 运行在独立 `QThread`
- 内部 `QTimer` 触发定时采集
- `onTimeout()` 中调用 `m_device.readData(...)`
- 通过 `dataReady(const Icm20608Data &data)` 把结果送回 UI

这种写法比把采集逻辑直接写在页面按钮槽里更专业，也更利于后续做：
- 高频采样
- 缓存
- 曲线
- 数据保存

---

## 6. Qt 页面层

### 路径
- `apps/qt_app/LSZ_Terminal/pages/sensorpage.*`

### 页面行为
在 `SensorPage` 中：
- 可设定 ICM20608 采样周期
- 点击 Start 启动 Worker
- 点击 Stop 停止 Worker
- 收到数据后显示：
  - `Accel X / Y / Z`
  - `Gyro X / Y / Z`
  - `Temp`

---

## 7. 当前链路总结

ICM20608 的完整链路可以概括为：

1. `dts/imx-emmc.dts` 中描述 `icm20608@0`
2. 驱动匹配并导出 `/dev/icm20608`
3. Qt 设备类读取字符设备
4. 在设备类内完成单位换算
5. Worker 周期采集
6. `SensorPage` 显示工程值

---

## 8. 与 AP3216C 的区别

### AP3216C
更偏“通道值显示”：
- IR
- ALS
- PS

### ICM20608
更偏“工程量显示”：
- 角速度
- 加速度
- 温度

因此 ICM20608 更适合作为后续：
- 多线程采集
- 数据缓存
- 曲线显示
- 简单惯性计算

的进一步练习入口。
