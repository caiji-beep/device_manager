# apps

`apps/` 目录存放用户态程序，分为两条线：

- `cli/`：最小验证程序
- `qt_app/LSZ_Terminal/`：Qt 图形界面应用

---

## 1. cli

CLI 程序的作用是：

- 先验证驱动导出的 `/dev/...` 接口是否工作
- 将问题隔离在“驱动层”还是“Qt 应用层”
- 作为后续图形界面开发之前的最小验证入口

典型使用方式：

- `ap3216cAPP`：循环读取 `IR / ALS / PS`
- `icm20608APP`：读取陀螺仪、加速度计和温度
- 其他模块可继续按相同思路扩展

---

## 2. qt_app / LSZ_Terminal

这是当前仓库里的主要图形界面应用。

它的目标不是简单做一个“把按钮放出来”的界面，而是围绕当前已经接通的底层设备，形成：

- 本地设备控制页面
- 串口监控页面
- 传感器采集页面
- 周期采集的 Worker 线程结构

如果你主要关心最终应用效果，请优先阅读：

- `qt_app/LSZ_Terminal/README.md`（如果后续单独补）
- `docs/QT_APP_LSZ_TERMINAL.md`

如果你主要关心模块链路，请结合 `docs/modules/` 下的文档阅读。
